# Pauso · Quiet Rhythm

A quiet Android companion that alternates sound and breaks.

## Download
[Download the latest Pauso.apk](https://github.com/wander-yd/pauso-releases/releases/latest/download/Pauso.apk)

Android 8 or newer. Download the APK, open it and confirm installation. Android may ask you to allow installation from your browser. Install updates over Pauso; do not uninstall first if you want to retain settings.

Pauso can check for new versions once a day when opened, with a manual Check for updates button. You still confirm each installation. Sound playback and timers work offline.

This repository contains only release APKs, update metadata, checksums and public release notes. Source code and signing keys are not published here.

Included nature sounds are CC0 recordings by stevenparry (Forest Rain, Freesound 760955) and Magnesus (Forest Birds, Freesound 723913), edited for Pauso. See the app's Sounds → Credits for sources. Noise is synthesized locally.
